# Install WTF

You can find WTF on [Moddb](https://www.moddb.com/mods/stalker-anomaly/addons/weird-task-framework) and [Github](https://github.com/Igigog/Weird_Task_Framework/releases). Use Moddb for the latest stable version.

[MCM](https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-mod-configuration-menu) is a hard requirement for WTF. Other than that, there are no dependencies.

WTF comes with a core framework and a few task packs bundled together. You should always install the core (named `Weird_Task_Framework`), and you can freely choose which task packs you want. Since all the quests can be disabled via [MCM](https://www.moddb.com/mods/stalker-anomaly/addons/anomaly-mod-configuration-menu), feel free to install all of them and disable the ones you don't want.

WTF uses quite a few techniques to avoid mod conflicts. Feel free to install it anywhere it your load order, I won't judge.
