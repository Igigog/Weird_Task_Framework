# Kill quest

```json
{
    "WTF_VERSION": "4.3",
    "description": {
        "locations": ["$ igi_description.get_smart_name_by_id(|squad.smart_id|)"]
    },
    "entities": [
    {
        "section_name":"bandit_sim_squad_alpha",
        "smart_id": "?$ wtf.shuffle(igi_finder.get_smarts(1,1))[1]",
        "HELPERS": ["@$ wtf.CreateSquad", "@$ wtf.ScriptedSquad"],
        "CONTROLLER":"@$ igi_target_kill.Kill",
        "squad_size": 3,
        "link_id": "squad"
    }
    ],
    "icon": "ui_inGame2_PD_master_boevih_sistem",
    "rewards": {
        "money": "@$ 2000 + 400 * |squad.squad_size|",
        "goodwill": "@$ 20 + 4 * |squad.squad_size|"
    },
    "quest_givers": [
        {"Mechanic": true}
    ]
}
```

Ah, the classic kill-type quest. You have one job: go to wherever the enemy squad is and ensure that it doesn't exist anymore. We use `?$` optional macro to ensure there exists a smart we want to place the enemy on, and we use `wtf.CreateSquad` helper to create it. After that, you're all set.

Setting up rewards requires a bit of nudging. Since the squad sizes are randomized on creation, you can't know squad size when accepting the task. Instead, we'll approximate the size at first; `wtf.CreateSquad` overrides it after squad creation.
