# GhenTuong Task Pack

It is not as known nowadays, but WTF started with GhenTuong's Task Pack. In fact, before WTF became WTF, it was just [Igi Tasks](https://www.moddb.com/mods/stalker-anomaly/addons/igis-tasks-obt-version) - a modified version of [GhenTuong Tasks](https://www.moddb.com/mods/stalker-anomaly/addons/ghentuong-tasks-pack-v2). In fact, the whole Framework/Task Pack split happened because I wasn't fine with just erasing Ghen's name from the tasks he created.

Oldies know, that the original GT Tasks addon had one more task: the helicopter one. I hated it, so that was the first thing I erased from existence. Some people still say Igi Tasks had a helicopter task; no, it didn't.

Other than that, it was real rough around the edges: it could spawn a pseudogiant in Cordon on first day, the descriptions were unnecessarily colourful and had arbitrary task ratings.

WTF's flavour of GT Tasks tend to have _some_ scaling of tasks: you'll be killing boars on your first day in the Zone, and you'll get to chimeras and pseudomutants after you've proven yourself. That doesn't mean they can't spawn in Cordon; they totally can, but the players of this level tend to leave Cordon anyway, so it works out somehow.
