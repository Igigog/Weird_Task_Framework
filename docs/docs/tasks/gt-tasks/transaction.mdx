Transaction is the older brother of [Supply chain](/tasks/gt-tasks/supply), with harder preconditions and better things to get if you're willing to fail the quest. Packages in Transaction can provide you with artifacts and guns.

What is funny, I now see that these packages do scale exactly how [Neutralization](/tasks/gt-tasks/heavy) does, but since the precondition is so high, you won't bee seeing level 1 of these packages.
