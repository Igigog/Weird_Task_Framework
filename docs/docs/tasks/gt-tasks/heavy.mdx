# Neutralization

<br/>

Neutralization is a classic Kill-type quest, not much to say about it except its scaling: you'll be at task level 1 from the start, task level 2 starts with 3000 player rank, and level 3 starts with 8000 player rank. All scales spawn 3-4 enemies, the only difference is the rank of the enemies - level 1 tends to spawn novices, at level 3 you'll be fighting masters.

Original GT Tasks had these squads _very_ heavily armed - we're talking exosuits, RPKs and RPGs. I tuned it down quite a bit.
