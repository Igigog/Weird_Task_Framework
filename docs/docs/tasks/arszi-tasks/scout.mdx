I love, love, love Scout task. It is such a simple concept - go to a list of locations, then go back - but it's perfect for early game, for small money on the side, for pacifist runs... It's just great.

I created an experimental feature in WTF which allows to create multiple map markers for a single quest just to make Scout even better.

The locations aren't actually random - Arszi created multiple lists for every location. IMO, that's overkill, but he was adamant that's how it should be, so the lists stayed even in WTF flavour of Arszi Tasks.
