# Arszi Task Pack

Arszi Task Pack was created from [Arszi Tasks](https://www.moddb.com/mods/stalker-anomaly/addons/arszis-immersive-dynamic-tasks) addon. Basically, the story behind it is: I was bored with GT Tasks, but I was too lazy to create my own, so I adopted Arszi's Tasks. The creation of Arszi Task Pack was the point where I split Igi Tasks into WTF and Task Packs. I think it was a great solution long term, since the original authors get full credit for the tasks, while I take care of support and improvements.

Curious people may find _Arszi's Realistic Assassinations_ in MCM, which is an option which will fail Kill- and Assault-type quests if someone else does them for you. That feature originally comes from Arszi Tasks, although I changed it a bit.
